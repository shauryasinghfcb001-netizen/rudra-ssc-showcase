#  SSC platform

Student task and study-management system for Rudra SSC workflows.

## What It Does

Rudra SSC is built for managing student study work, daily focus, assigned tasks, and mentor/admin control across an education workflow.

## Highlights

- Student-facing daily focus experience.
- Admin-controlled task assignment.
- Selected-student task targeting.
- Study and task visibility logic.
- Designed around real coaching-center operations.

## Built For

Coaching teams that need a cleaner way to guide student work without losing accountability.
