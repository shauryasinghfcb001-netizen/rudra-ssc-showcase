Features and how the system connects

A public site, a student portal and a mentor admin panel, all running on one database with row-level security.

How it is connected

Three front-ends talk to one Supabase backend. Students are created by a server function that generates their ID and password. Payments go out through Razorpay links, leads go to WhatsApp.
